# Ресёрч: защита Minecraft-сети (август 2026)

Выжимка исследования защиты. Полный контекст: сеть Velocity + Paper 26.2, offline-mode + LibreLogin, Geyser/Floodgate, VPS 2 vCPU / 8 GB без внешней DDoS-фильтрации.

## Античит
- **GrimAC** (free, open-source) — выбор для запуска: активная разработка (сборки почти еженедельно), поддержка 1.7.2–26.2, **автоматически исключает Bedrock-игроков через Floodgate API** (движение Bedrock — client-authoritative, все серьёзные АЧ их исключают, иначе ложные баны). Важно: Floodgate должен стоять на backend-серверах (у нас стоит).
- Свой античит НЕ пишем: это многолетний специализированный проект (симуляция физики, анализ пакетов), Grim закрывает потребность бесплатно.
- Апгрейд позже: **Vulcan** ($19.99 разово, пара к Grim: Grim — движение, Vulcan — комбат) или **Polar** (облачный, €15+/мес — уточнить поддержку Bedrock у саппорта). Matrix ~$25. Intave закрылся (2025), Themis без 26.x, NoCheatPlus-форки ложно флагают Bedrock.
- Для проверки самих Bedrock-игроков есть экспериментальный **Boar** (free) — опционально позже.
- Bedrock-читеры: ручная модерация (все АЧ их исключают) — осознанное ограничение кроссплея.

## Антибот (бот-атаки на offline-серверы)
- **Sonar 2.1.50** (free, поддержка 26.2) — верификация новых IP во внутреннем limbo до попадания на backend (протокол/гравитация/коллизии), очередь подключений. ⚠️ `transfer.enabled` держать **false** — Geyser не транслирует transfer-пакет.
- **EpicGuard 7.6.1** — слой гео/VPN-фильтра, лимиты аккаунтов с IP, режим lockdown при рейде.
- Встроенное в Velocity: login-ratelimit 3000ms/IP, лимиты команд и tab-complete.
- LibreLogin: кик неавторизованных по таймауту (у нас 300 с) — ограничивает ущерб от проскочивших ботов.
- Капчи в одиночку (LimboFilter-подход) в 2026 обходятся ИИ-решалками — только слоёная защита. RU-мета: Sonar + гео/ASN-фильтры + пер-протокольный троттлинг + ядрёный firewall.

## DDoS-реальность
Что прилетает малым серверам: SYN-флуд на 25565, UDP/RakNet-спам на 19132 (Geyser), L7 джоин-флуд (см. антибот), спам статус-пингов.
- **Уровень VPS (bare)**: nftables — synproxy на TCP, лимиты новых соединений на IP, pps-лимиты и отсечение не-RakNet на UDP 19132. Готовые референсы: github.com/Alexitru/nftables-minecraft-ddos-mitigation. Против забития канала (1 Gbps) VPS бессилен — только внешний фильтр.
- **Внешние фильтры**: TCPShield Free (1 ТБ/мес, только Java; haproxy-protocol на Velocity + firewall только на их диапазоны + в идеале смена IP); NeoProtect (free-тир Java); **Infinity-Filter** (free ≤20 игроков, €1.79–5.99/мес — единственный дешёвый вариант С Bedrock/UDP). Cloudflare Spectrum — неэкономично.
- **Когда переезжать** на хост со встроенной фильтрацией (OVH Game и подобные): когда атаки, забивающие канал, становятся регулярными. Наш переезд на другой VPS и так запланирован — учесть фильтрацию при выборе.
- Bedrock UDP бесплатно почти не фильтруется — на старте только nftables + встроенный RakNet-лимитер Geyser.

## Крэш-эксплойты
- Современный Paper закрывает классику сам: book-ban (лимиты страниц), NBT-бомбы, oversized-пакеты. Встроенный packet-limiter в paper-global.yml (кик при >500 пакетов/7с, настраивается по типам) — плагины-лимитеры не нужны.
- На proxy: **AntiCrasher 2.0.11** (стоит) — фильтр malformed-пакетов. Не ставить «улучшенные форки Velocity» — минимум один распространяется группой эксплойтеров.
- Главная дыра offline-сетей — прямой заход на backend мимо proxy под любым ником: у нас закрыто (bind 127.0.0.1 + modern forwarding с секретом). При выносе backend на другие машины — только private network + firewall.

## Харденинг VPS (к prod-этапу)
- SSH: только ключи, PermitRootLogin no (после создания отдельного юзера), fail2ban.
- Firewall default-deny: наружу только 22 (или нестандартный SSH-порт), 25565/tcp, 19132/udp (+dev-порты по желанию), 80/443 для сайта.
- Никогда не наружу: backend-порты Paper, PostgreSQL, RCON (выключен), веб-панели плагинов (только за reverse proxy с auth).
- MC-процессы под непривилегированным юзером в systemd (сейчас root — исправить на prod-этапе).
- unattended-upgrades; обновлять Paper/Velocity/Geyser еженедельно (фиксы эксплойтов едут постоянно).
- Оффсайт-бэкапы миров и БД — часть защиты (восстановление после гриферства/шифровальщика).

## Итоговая карта «атака → защита»
| Атака | Что закрывает |
|---|---|
| Бот-атака (масс-джоины) | Sonar → EpicGuard → login-ratelimit → кик по таймауту LibreLogin |
| SYN/L4-флуд 25565 | nftables/synproxy (prod), затем TCPShield Free |
| UDP/RakNet-флуд 19133 | nftables pps-лимиты + RakNet-лимитер Geyser (полноценно — платный фильтр) |
| Статус-пинг спам | Sonar + rate-limit на крае |
| Крэш-эксплойты | Сток Paper 26.2 + packet-limiter + AntiCrasher + еженедельные обновления |
| Обход proxy на backend | bind 127.0.0.1 + modern forwarding secret |
| Читеры Java | GrimAC (позже + Vulcan) |
| Читеры Bedrock | исключены из АЧ — ручная модерация (позже Boar) |
