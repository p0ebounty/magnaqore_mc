# STYLE — дизайн-система MagnaQore (игровой UI)

> Требование владельца: никаких «дефолтных фразочек» — все игровые сообщения, меню, таб, скорборд, титулы выдержаны в одном фирменном стиле, как кастомные компоненты вместо браузерных дефолтов. Всё двуязычно RU/EN (по локали клиента, где технически возможно).

## Палитра
| Роль | Цвет | Использование |
|---|---|---|
| Бренд-градиент | `#8A2BE2 → #00CED1` (фиолет → бирюза) | логотип-текст «MagnaQore», заголовки, MOTD, титулы |
| Акцент | `#00CED1` (aqua) | команды, ссылки, интерактив, имена |
| Текст | `<gray>` | основной текст сообщений |
| Приглушённый | `<dark_gray>` | разделители, скобки, «»», второстепенное |
| Успех | `#7CFC9B` | подтверждения |
| Ошибка/опасность | `#FF6B6B` | ошибки, предупреждения (не ванильный красный) |
| Внимание | `#FFD37C` | нейтральные предупреждения |

## Анатомия сообщений (MiniMessage)
- **Бренд-метка** (вместо префиксов в скобках): `<gradient:#8A2BE2:#00CED1><b>MQ</b></gradient> <dark_gray>›</dark_gray> ` — короткая, не мусорит чат.
- **Системное сообщение**: `MQ › <gray>текст с <aqua>акцентами</aqua></gray>`
- **Успех**: `MQ › <#7CFC9B>Готово:</#7CFC9B> <gray>…</gray>`
- **Ошибка**: `MQ › <#FF6B6B>…</#FF6B6B>`
- **Чат игрока**: `<уровень-префикс> <white>ник</white> <dark_gray>»</dark_gray> <gray>сообщение</gray>` — без квадратных скобок, без тяжёлых плашек.
- **Вход/выход**: `<dark_gray>[</dark_gray><#7CFC9B>+</#7CFC9B><dark_gray>]</dark_gray> <gray>ник</gray>` / с `<#FF6B6B>-</#FF6B6B>` — лаконично, как у крупных серверов.
- Титулы: заголовок — бренд-градиент жирным, подзаголовок — `<gray>`.

## Принципы
1. **Меньше — дороже**: короткие фразы, никаких стен текста, ни одного CAPS.
2. Один разделитель везде: `›` для системных, `»` для чата.
3. Ванильные механики, которые уже локализованы клиентом (сообщения смерти, названия предметов), не переписываем без нужды — они бесплатно двуязычные; но оформляем их обвязку.
4. Каждое сообщение существует в RU и EN. В местах без пер-игрока локали (MOTD, NanoLimbo) — двухстрочный RU/EN или нейтральный бренд-текст.
5. Все строки — MiniMessage (никаких legacy `&`-кодов в наших конфигах, кроме плагинов, где иначе нельзя).
